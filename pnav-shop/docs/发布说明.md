# v1.0.0 发布说明

首个公开版本：只围绕「格连商店」这一页。

## 功能

- **自动寻路**：蓝色导航点识别 + HUD「N 米」判断，走到商店门口自动停
- **进店截图**：检测到「F 进入格连商店」→ 进店 → 等画面亮起 → 连拍 → 拼 `sheet.png`
- **桌面分身**：`CreateDesktopW` 第二桌面 + `CreateProcess` 启动游戏，主桌面不受干扰
- **分身小窗**：实时画面（PrintWindow），窗口内点击走 `PostMessage`，真实鼠标不动
- **一键停止**：寻路/截图随时停，分身不关
- 参数：输出标签、截图张数、每张转角、时间预算、最大步数
- 只认 `PetitPlanet.exe` 进程的窗口，避免误发按键
- 命令行：`--phase nav|shop|both`

## 依赖

Windows 10/11 x64、Python 3.10+、numpy；创建分身需管理员。
游戏窗口化、客户区 1920×1080。

## 已知问题

- 非 1920×1080 客户区时转向会偏；
- 游戏最小化时无法截图；
- 分身里游戏能否持续渲染取决于引擎，请先切过去确认一次；
- 窄桥/贴墙地形可能耗时较长；
- 某些游戏不响应 PostMessage，小窗点击可能无效。
