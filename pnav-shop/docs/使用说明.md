# 使用说明

## 0. 准备

1. 游戏设为**窗口化/无边框**，客户区 1920×1080；
2. 站在任意星球户外，让屏幕能看到蓝色导航点（没有就点一次「寻找友邻」锁定格连）；
3. `py -3 -m pip install numpy`，然后双击 `启动格连商店.bat`。

## 1. 先验证寻路（不开分身）

点「启用寻路」：程序右键一次确保奔跑 → 循环（截图 → 找蓝点 → 微调 → 前进 → 读「N米」）
→ 看到「F 进入格连商店」就停。

日志示例：

```
[ 1.2s] window: 星布谷地 (#123456)
[ 1.3s] === walk only: head for the 格连 shop ===
[ 2.0s]   dot=(923,523) dx=-37 12米 aim -22
[ 3.4s]   step 1: 12米 -> 9米 dot moved 41px
[ 5.1s]   arrival prompt found score=0.942
```

## 2. 桌面分身（可选）

1. **以管理员身份运行**本程序（否则起不了游戏：`CreateProcess 740`）；
2. 点「创建分身并启动游戏」，等日志出现「分身窗口就绪」（最多 180 秒，可能要登录）；
3. 会自动打开**分身小窗**：里面是实时画面，点击直接作用在游戏上，
   真实鼠标不动，你可以继续在主桌面干别的；
4. 点「小窗：寻路+截图」，它会在分身里走完并进店拍照；
5. 用完点「结束分身」（连同游戏进程一起关闭）。

## 3. 只进店拍照

人已经在店里时点「启用截图」：等画面亮 → 向里走一点 → 按 `截图张数` 拍，
每张转 `每张转角` 像素 → 拼 `sheet.png`。

## 4. 参数

| 参数 | 含义 | 建议 |
| --- | --- | --- |
| 输出标签 | 输出子目录名 | 用日期，如 `1028` |
| 截图张数 | 一圈拍几张 | 6 |
| 每张转角 | 每张之间转多少像素 | 1500（≈60–70°） |
| 时间预算 | 寻路最长多久 | 600 秒 |
| 最大步数 | 最多前进几次 | 90 |

## 5. 常见问题

**Q：「没找到游戏窗口」**
游戏没启动或最小化了；程序只认进程 `PetitPlanet.exe`。点「选择窗口」手动挑。

**Q：一直看不到蓝点**
游戏里还没锁定格连，或蓝点被完全遮挡。先在游戏里点一次「寻找友邻」。

**Q：为什么原地跳/后退/左右转**
脱困逻辑：距离不再变小说明前面挡住了，按"跳→退→换边→转向"试，
并记录哪种有效（`reports/stuck_stats.json`）。

**Q：小窗里点了没反应**
某些游戏不响应 `PostMessage` 鼠标消息。可以切到游戏窗口直接用真实鼠标操作，
或把游戏放回主桌面（不要创建分身）。

**Q：会被封号吗**
不注入、不改内存，但用户协议通常禁止第三方自动化，**存在风险**，见 `DISCLAIMER.md`。

## 6. 卸载

删除文件夹即可，不写注册表、不装服务。
